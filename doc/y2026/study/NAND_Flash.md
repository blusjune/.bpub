6m 2s 동안 처리함

NAND 플래시는 ‘전하를 가둬 두어 정보를 보관하고, 그 전하가 트랜지스터의 전류 흐름을 얼마나 어렵게 만드는지 측정해서 읽는 비휘발성 메모리’입니다. 컴퓨터 시스템 관점에서는 다음 세 가지를 먼저 잡으시면 전체 구조가 쉽게 연결됩니다.

- 셀은 전하로 정보를 기억합니다.
- 읽기·쓰기는 페이지 중심, 지우기는 더 큰 블록 단위로 수행합니다.
- SSD는 이러한 제약을 컨트롤러가 관리하여 일반적인 저장장치처럼 보이게 만든 시스템입니다. SSD는 Solid-State Drive, 반도체 저장장치입니다. [1][2]

아래는 셀 하나 → 셀들의 연결 → 읽기·쓰기·지우기 → SSD 동작 순서로 구성한 입문 자료입니다. 그림의 크기, 전자 개수, 전압과 애니메이션 시간은 원리 설명용이며 실제 제품 사양이 아닙니다.

1. 무엇을 저장하는가: ‘전압 자체’보다 ‘전류가 흐르기 시작하는 조건’을 기억합니다

일반적인 트랜지스터는 게이트에 가하는 전압으로 전류 통로를 조절하는 스위치라고 생각하시면 됩니다.

구성 요소	역할

Source·Drain, 소스·드레인	전류 통로의 양 끝
Channel, 채널	소스와 드레인 사이에서 전류가 흐르는 길
Control Gate, 제어 게이트	전압을 가해 채널 형성을 조절하는 전극
전하 저장층	정보를 표현하는 전하를 보관하는 영역
절연층	저장 전하가 쉽게 빠져나가지 못하도록 하는 장벽


NAND 셀은 여기에 전하를 보관하는 영역을 더한 구조입니다. 저장 전자가 많아지면, 같은 게이트 전압에서도 채널을 형성하기가 어려워집니다. 따라서 전류를 흐르게 하려면 더 높은 게이트 전압이 필요합니다.

이때 사용하는 핵심 개념이 문턱전압, \(V_{\mathrm{th}}\) — Threshold Voltage입니다. 정해진 조건에서 채널이 충분히 전도하기 시작하는 게이트 전압을 뜻합니다. 저장 전하가 달라지면 문턱전압이 달라지고, 이 차이로 데이터를 구분합니다. [1]

아래에서 Program → Read → Erase 순서로 눌러 보십시오. Program 이후 읽기 전압 슬라이더를 올리면, 저장 전하를 바꾸지 않아도 전류 감지 결과가 달라지는 것을 볼 수 있습니다.

여기서 중요한 구분은 다음과 같습니다.

> 저장 상태는 ‘문턱전압이 어디에 있는가’이고, 읽기는 ‘정해진 기준 전압에서 전류가 흐르는가’를 확인하는 과정입니다.



따라서 읽기 기준을 잘못 잡으면 저장 상태가 그대로인데도 잘못 판정할 수 있습니다. 실제 셀의 전류는 완벽한 ON/OFF로 갑자기 바뀌지 않으며, 그림은 이를 단순화한 모델입니다. [1][3]

전원이 꺼져도 절연층 안의 전하 상태가 유지되므로 비휘발성입니다. 다만 영구 보존을 뜻하지는 않습니다. 시간·온도·마모에 따라 전하와 문턱전압이 변할 수 있습니다. [4]

2. 실제 셀 구조: 전하를 저장하는 방법과 셀을 쌓는 방법을 구분해야 합니다

전하 저장 방식에는 대표적으로 두 종류가 있습니다.

방식	전하가 저장되는 곳	이해를 위한 비유

FG — Floating Gate, 부유 게이트	절연체에 둘러싸인 전도성 영역	외부와 전기적으로 끊어진 작은 금속 섬
CT — Charge Trap, 전하 포획	절연성 재료 안의 전하 포획 위치	전자가 머물 수 있는 작은 자리들이 있는 층


많은 현대 3D NAND — Three-Dimensional NAND, 3차원 NAND는 전하 포획 방식을 사용합니다. 다만 모든 NAND가 같은 저장 구조를 사용하는 것은 아닙니다. [4]

별도로, 2D와 3D는 셀 배치 방식의 차이입니다.

- 2D NAND: 셀들을 주로 실리콘 표면의 평면 방향으로 배치합니다.
- 3D NAND: 워드라인 층들을 높이 방향으로 쌓고, 이를 관통하는 수직 채널을 형성합니다. 채널 주변의 각 높이에 셀이 만들어집니다.

3D NAND의 ‘층을 쌓는다’는 것은, 패키지 안에 완성된 반도체 다이를 여러 장 쌓는 것과 구별되는 개념입니다. 하나의 다이 내부에 메모리 셀 구조를 수직으로 형성하는 것입니다. [5]

3. 왜 NAND라고 부르는가: 셀들이 직렬로 연결됩니다

NAND는 NOT AND에서 유래한 이름이며, 메모리 셀의 직렬 연결 구조와 관련됩니다. 데이터를 읽을 때 NAND 논리 연산으로 파일을 복원한다는 뜻은 아닙니다. [1][2]

먼저 세 가지 연결을 보시면 됩니다.

- String, 스트링: 여러 셀을 직렬로 연결한 전류 경로입니다.
- WL — Word Line, 워드라인: 여러 셀의 게이트를 함께 제어하는 선입니다.
- BL — Bit Line, 비트라인: 스트링에 연결되어 전류를 감지하는 데 사용하는 선입니다.
- SL — Source Line, 소스라인: 스트링의 소스 쪽에 연결되는 선입니다.

직렬 연결에는 문제가 하나 있습니다. 중간의 셀 하나만 꺼져 있어도 전체 경로의 전류가 차단됩니다. 그러면 읽고 싶은 셀 때문인지, 다른 셀 때문인지 알 수 없습니다.

그래서 읽을 때는 다음과 같이 제어합니다.

1. 선택한 셀: 저장 상태를 판정할 읽기 전압을 가합니다.
2. 나머지 셀: 저장 상태와 관계없이 통로를 열도록 충분한 통과 전압, \(V_{\mathrm{pass}}\) — Pass Voltage을 가합니다.
3. 스트링 전류를 감지하여 선택 셀의 상태를 판정합니다. [6]

아래에서 워드라인을 바꾸고 페이지 읽기 실행을 눌러 보십시오. 각 셀 안의 숫자는 문턱전압입니다. 선택하지 않은 셀은 통과 전압으로 켜지고, 선택한 행의 셀들이 각 스트링의 전류를 결정합니다.

이 그림은 전기적 연결 개념도입니다. 실제 3D NAND에서는 수직 채널을 따라 셀들이 배치되고, 게이트가 채널을 둘러싸는 형태를 사용합니다. 상·하단의 선택 게이트는 스트링을 연결하거나 분리합니다. [5]

4. 셀에서 칩까지: 페이지와 블록의 차이가 핵심입니다

컴퓨터 시스템에 익숙하시다면 물리적 구조와 접근 단위가 서로 다르다는 점을 주의해서 보시면 됩니다.

용어	의미	시스템 관점의 중요성

Cell, 셀	전하 상태로 정보를 저장하는 소자	셀당 저장 비트 수를 결정
Page, 페이지	많은 셀의 비트를 묶은 데이터 단위	일반적인 읽기·프로그램의 기본 단위
Block, 블록	여러 페이지가 속하는 영역	기본적인 지우기 단위
Plane, 플레인	다이 안의 메모리 어레이 구획	조건에 따라 병렬 동작에 활용
Die, 다이	하나의 반도체 조각	내부 동작과 병렬성의 주요 단위
Package, 패키지	하나 이상의 다이를 담은 부품	보드에 실장되는 물리적 부품


페이지 크기, 블록당 페이지 수, 플레인 수는 제품마다 다릅니다. 또한 워드라인 하나가 항상 데이터 페이지 하나와 같지는 않습니다. 셀당 여러 비트를 저장하면 같은 셀 집합이 여러 논리 페이지의 데이터를 담을 수 있습니다. [2][6]

따라서 호스트의 4 KiB 쓰기 요청이 NAND 내부의 페이지 프로그램 한 번과 정확히 일치한다고 생각하시면 안 됩니다.

5. 핵심 동작: Read는 측정, Program은 상태 조정, Erase는 블록 초기화입니다

① Read, 읽기 — 저장 전자를 꺼내서 세는 과정이 아닙니다

선택 워드라인에 읽기 기준 전압을 가하고, Sense Amplifier, 감지 증폭기가 스트링의 전류 또는 그에 따른 비트라인 전압 변화를 판정합니다. 판정한 데이터는 페이지 버퍼를 거쳐 외부로 전달됩니다.

단일 비트 셀의 기본 설명에서는 낮은 문턱전압을 1, 높은 문턱전압을 0으로 대응시킵니다. 실제 사용자 데이터와 셀 상태 사이에는 데이터 변환과 오류 정정 과정도 존재합니다. [1][2][6]

② Program, 쓰기 — 목표 문턱전압까지 조금씩 이동시킵니다

높은 전기장을 이용하여 전자를 저장층에 주입하고 문턱전압을 높입니다. 절연 장벽을 통과하는 주요 원리로 FN Tunneling — Fowler–Nordheim Tunneling, 파울러–노르트하임 터널링을 사용합니다.

정확한 상태를 만들기 위해 흔히 ISPP — Incremental Step Pulse Programming, 점증 펄스 프로그램을 사용합니다. 프로그램 펄스를 가한 뒤 목표에 도달했는지 확인하는 Verify, 검증 읽기를 반복합니다. 목표에 도달한 셀에는 추가 주입을 억제합니다. [6][7]

③ Erase, 지우기 — 셀을 다시 프로그램할 수 있는 상태로 돌립니다

일반적인 데이터 갱신에서는 프로그램으로 높인 문턱전압을 원하는 만큼 자유롭게 낮추지 못하므로, 지우기 과정이 필요합니다. 지우기는 기본적으로 블록 단위입니다. [2]

첫 애니메이션은 평면형 셀에서 전자를 빼내는 개념으로 표현했습니다. 실제 3D 전하 포획 NAND에서는 정공을 공급·주입하여 저장 전하 상태를 바꾸는 방식도 중요합니다. 따라서 지우기를 모든 구조에서 단순히 “전자를 반대 방향으로 이동시키는 것”으로만 이해하면 부족합니다. [5]

6. 셀 하나에 어떻게 여러 비트를 넣는가: 더 많은 문턱전압 구간을 구별합니다

셀 하나에 독립적인 스위치를 여러 개 넣는 것이 아니라, 하나의 셀이 가질 수 있는 문턱전압 상태를 더 세밀하게 나눕니다.

종류	전체 명칭	셀당 비트	구별해야 하는 상태 수

SLC	Single-Level Cell	1	2
MLC	Multi-Level Cell, 통상 2비트 제품을 지칭	2	4
TLC	Triple-Level Cell	3	8
QLC	Quad-Level Cell	4	16


\(b\)비트를 저장하려면 \(2^b\)개의 상태를 구별해야 합니다. 예를 들어 TLC는 여덟 상태 각각에 서로 다른 3비트 조합을 대응시킵니다. 실제 비트 조합의 배치 순서는 구현에 따라 달라집니다.

중요한 점은 상태 하나가 정확한 전압 한 점이 아니라, 여러 셀의 문턱전압이 퍼져 있는 분포라는 것입니다. 제한된 전압 범위에서 상태 수를 늘리면 구간 사이의 여유가 줄어들어, 더 정교한 프로그램과 읽기가 필요합니다. 일반적으로 용량·비트당 비용에는 유리하지만 속도·내구성·오류 관리에는 부담이 커집니다. [3]

3D 적층은 셀의 개수를 늘리고, TLC·QLC는 셀 하나가 담는 비트 수를 늘립니다. 두 기술은 함께 사용할 수 있습니다.

7. SSD에서 왜 ‘덮어쓰기’가 복잡한가: 새 위치에 쓰고 주소를 바꿉니다

호스트가 같은 주소의 데이터를 수정해도 SSD는 보통 기존 페이지를 직접 덮어쓰지 않습니다. FTL — Flash Translation Layer, 플래시 변환 계층이 새 페이지에 데이터를 기록하고 논리 주소가 가리키는 물리 위치를 변경합니다.

이후 GC — Garbage Collection, 가비지 컬렉션이 남아 있는 유효 데이터를 옮기고 오래된 블록을 지워 공간을 회수합니다. 아래에서 전체 재생을 누르면 이 순서를 볼 수 있습니다. [6]

이 때문에 호스트가 보낸 데이터 외에도 내부 복사 쓰기가 발생합니다. 이를 나타내는 지표가 WAF — Write Amplification Factor, 쓰기 증폭 계수입니다.

\[
\mathrm{WAF}=
\frac{\text{NAND에 실제 기록한 데이터량}}
{\text{호스트가 기록하도록 요청한 데이터량}}
\]

또한 반복적인 P/E — Program/Erase, 프로그램·지우기는 절연층과 계면에 손상을 축적합니다. SSD는 Wear Leveling, 마모 평준화로 특정 블록에 마모가 집중되지 않게 관리합니다. [4][6]

읽을 때 생기는 비트 오류에는 ECC — Error-Correcting Code, 오류 정정 코드 등을 사용합니다. 즉, SSD의 신뢰성은 셀의 품질뿐 아니라 셀의 불완전함을 감지하고 보정하는 시스템 기술에도 의존합니다. [6]
